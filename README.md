# MIR - Harmonics on Cretan Music

This repository focuses on Music Information Retrieval (MIR) techniques, specifically the harmonic analysis of Cretan music. The project is implemented primarily in Jupyter Notebook format.

## Contents

- [`harmony_comparison_analysis.ipynb`](https://github.com/panteleimon-a/MIR---Harmonics-on-Cretan-Music/blob/master/harmony_comparison_analysis.ipynb):  
  Main notebook for analyzing and comparing harmonic features in Cretan music.

## Features

- Harmonic analysis of traditional Cretan music recordings
- Visualization and comparison of harmonic content
- Data-driven insights with MIR methods

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/panteleimon-a/MIR---Harmonics-on-Cretan-Music.git
2. Navigate to the project directory and start Jupyter Notebook:
```bash
    cd MIR---Harmonics-on-Cretan-Music
    jupyter notebook
```
3. Open and run the notebook:
Use the Jupyter interface to open harmony_comparison_analysis.ipynb.
## Requirements
- Python 3.x
- Jupyter Notebook
- Libraries:
- librosa
- numpy
- matplotlib
Install dependencies with pip if needed:
```bash
    pip install librosa numpy matplotlib
```
